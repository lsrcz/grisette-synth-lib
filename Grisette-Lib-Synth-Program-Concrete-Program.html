Grisette.Lib.Synth.Program.Concrete.Program

Description

Do not use plain concrete programs on operators that may generate multiple results that cannot be merged into a single result, or there can be significant performance issues.

Use the ProgMayMultiPath wrapper to allow multiple results. However, note that it is generally not a good idea to use non-simply-mergeable types as results, as it can lead to exponential blowup in the number of results.
